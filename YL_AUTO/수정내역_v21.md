# YL_AUTO v21 수정 내역 (2026-11-24, 깨진 CAD 용 최후의 메셔 TetWild)

## 왜
Part2, Part5, Part6 은 모두 CAD 자체에 결함이 있었고 결함 종류가 매번 달랐다.
| 모델 | CAD 결함 | 실패한 곳 |
|---|---|---|
| Part2 | 넓이 ~0 인 찌꺼기 면 4개, 길이 0 모서리 (솔리드 무효) | gmsh `Impossible to mesh periodic surface` |
| Part5 | 폭 ~0 인 띠 면, 3장이 만나는 모서리 (솔리드 무효) | YL_V10 V9/V8 스킨 불합격, gmsh 프로그램 강제 종료 |
| Part6 | 표면끼리 관통 | YL_V10 불합격, gmsh `PLC Error: A segment and a facet intersect` |

이런 결함을 하나씩 찾아 고치는 방식은 끝이 없다. 그래서 **결함이 있는 표면을 처음부터 입력으로 가정하고 만든 방법(TetWild)** 을
마지막 단계로 넣었다. 메시 단계 순서 :

```
1) YL_V10 (HyperMesh BatchMesher -> V8)     <- 정상 CAD 는 여기서 끝
2) gmsh (작은 면 직접 채우기 포함)            <- Part2 같은 경우
3) TetWild (OpenCASCADE 삼각형화 + TetWild)  <- [새로] 구멍/겹침/자기관통이 있어도 메시
```

## TetWild 방식이 하는 일
1. CAD 를 OpenCASCADE 로 촘촘한 삼각형으로 바꾼다. 면을 하나씩 삼각형화하므로 일부 면이 깨져도 나머지는 그대로 나온다.
2. 그 삼각형 전체를 품는 Tetra 메시를 공간에 만든 뒤 품질을 최적화하고, 표면 안쪽(winding number)만 남긴다.
3. 결과 표면은 원래 CAD 표면에서 `envelope_mm`(기본 0.05 mm) 이내로 유지된다.

## 설정 (`config_abaqus.json` 의 `robust_fallback`)
| 항목 | 기본 | 뜻 |
|---|---|---|
| `enabled` | true | 앞의 메셔가 모두 실패하면 TetWild 사용 |
| `envelope_mm` | 0.05 | 결과 표면이 CAD 에서 벗어나도 되는 거리 |
| `stop_energy` | 20 | 품질 목표 (작을수록 품질 좋고 오래 걸림). 100 이면 빠르지만 납작한 요소가 남음 |
| `timeout_min` | 90 | 모델당 제한 시간 |

## 설치 (연구실 PC, Python 3.9 용 패키지 있음)
```
pip install wildmeshing cadquery-ocp
```
없으면 이 단계만 건너뛴다 (로그에 안내).

## 검증 (여기서 실제 STEP 파일로)
| 모델 | 방법 | Tetra | 부피 (CAD 대비) | 최소 품질 | 품질<0.02 | 시간 (4코어) |
|---|---|---|---|---|---|---|
| Part5 | TetWild, stop_energy 100 | 243,430 | +0.007 % | 0.0055 | 174 | 8 분 |
| Part5 | TetWild, stop_energy 20 (기본) | 171,772 | -0.03 % | 0.058 | 0 | 23 분 |
| Part6 | TetWild, stop_energy 100 | 243,959 | -0.017 % | 0.0052 | 66 | 8 분 |

- Part5, Part6 모두 원점/INNER/OUTER 자동 판별 정상 (INNER = 보어, OUTER = 바깥 원통, 반경 방향 스웨징).
- 연구실 PC 는 코어가 더 많아 더 빠를 것으로 본다.
- **실제 HyperMesh/Abaqus 로는 확인하지 못했다.** HyperMesh 는 가짜(실패)로, Abaqus 는 가짜로 대신했다.

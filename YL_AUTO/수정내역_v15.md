# YL_AUTO v15 수정 내역 (2026-11-17, 요소크기 완전 고정 모드)

## 배경
지금까지 최종 메시는 YL_V4 알고리즘이 아니라 **단순 메시(전체 면 2 mm 균일 Tria -> Tetra)** 였다
(YL_V4 단계는 매번 Tetra 0개 또는 구멍 때문에 건너뜀, hm_status 의 `ALGO=FALLBACK_SIMPLE`).
그런데 v9~v14 에서 단순 메시가 실패하면 요소를 1.4 mm 로 줄여 다시 시도했고, Tetra 내부 성장률 1.2(v8 부터)
때문에 안쪽 Tetra 는 2 mm 보다 커질 수 있었다.

## 바뀐 점 : `config_abaqus.json` 의 `mesh.fixed_size: true` (기본값으로 켬)
| 항목 | fixed_size=false (예전) | fixed_size=true (지금) |
|---|---|---|
| 단순 메시 재시도 | 2 mm -> 2 mm(작은 면 더 무시) -> **1.4 mm** | 2 mm -> 2 mm(작은 면 더 무시). 크기는 안 줄임 |
| Tetra 내부 성장률 | 1.2 (안쪽으로 갈수록 커짐) | **1.0** (안쪽도 표면과 같은 크기) |
| solid 직접 메시 최소 크기 | 요소크기 x 0.52 | 요소크기 |
| gmsh 예비 메셔 최소 크기 | 요소크기 x 0.15 | 요소크기 |

- YL_V4 알고리즘 자체(Case A/B, 곡률 적응 0.52~1.15배)는 원본 코드 그대로 두었다.
- 설정을 바꾸면 이전 메시를 재사용하지 않고 자동으로 다시 메시한다 (`hm_status.txt` 에 `FIXED_SIZE`, `TET_GROWTH` 기록).
- 예전처럼 하려면 `"fixed_size": false`.

## 알아둘 점
- 크기를 줄이는 재시도가 빠졌으므로 **2 mm 로 메시가 안 되는 모델은 실패로 끝날 수 있다.**
  (받은 로그에서는 1.4 mm 재시도가 성공한 모델이 하나도 없었으므로 결과가 나빠지지는 않을 것으로 본다.)
- gmsh 는 최소=최대=2 mm 로 줘도 0.2 mm 글자 같은 작은 형상 근처에서는 짧은 모서리가 생긴다
  (시험 부싱: 모서리 길이 중앙값 1.98 mm, 5%~95% 범위 0.47~3.17 mm). CAD 형상이 그만큼 작기 때문이다.

## 검증 범위
- 모의 HyperMesh : 고정 모드에서 Tetra 파라미터가 `tet: 35 1.0 ...` 로 바뀌고 1.4 mm 시도가 빠지는 것 확인.
- gmsh : 0.2 mm 글자 부싱을 고정 모드로 실제 메시 (Tet 88,506개, 최소 품질 0.08).
- 설정 변경 시 재메시, 두 번째 실행에서 재사용되는 것 확인.
- **실제 HyperMesh 2019 에서는 확인하지 못했다.**

## 다시 실행 (설정이 바뀌어 메시부터 자동으로 다시 만듦)
```
run_all.bat --force
```

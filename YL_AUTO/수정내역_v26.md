# YL_AUTO v26 수정 내역 (2026-11-27, 헥사 0개 원인 + 자동 헥사 실험 기능)

## 증상 (연구실 실행 결과, 모델 7개)
- 7개 모두 `YL_HEX : 헥사 0개; 매핑 안 된 솔리드 1/1개` -> 메시 실패 -> 해석(ODB) 단계로 가지 않음
- `M11_27_1109295_00_C_LHS_bushing.hm` 에는 **CAD 형상만 있고 요소는 0개**다.
  YL_HEX_V6 의 3D 모드는 시작할 때 기존 요소를 지우고 SolidMap 을 실행한 뒤 결과와 상관없이 .hm 을 저장한다.
  SolidMap 이 아무것도 만들지 못했으므로 형상만 저장되었다.

## 원인
- YL_HEX_V6 (HyperMesh SolidMap, quads_only) 는 **매핑 가능한(블록으로 나눈) 솔리드**에서만 헥사를 만든다.
  원본 스크립트의 GUI 설명도 `3D Hexa volume (Multi-Solid Map - needs mappable solids)` 이다.
- 7개 부싱은 각각 공극, 필렛, 얇은 고무막이 있는 **한 덩어리 솔리드**라서 통째로 매핑이 안 된다 (`Unmappable: 1`).
- 이 경우 원본 스크립트도 "Geom -> Solid Edit -> Trim 으로 매핑 가능한 블록으로 나누라"고만 안내하며, 자동으로 나누는 기능은 없다.
- 코드 오류가 아니라 SolidMap 방식의 한계다. v25 에서 Tetra 로 넘어가는 동작을 지웠기 때문에 메시 실패로 끝났다.

## 바뀐 것
### 1. 실패 안내 문구
- 헥사 전용 모드에서 메시가 실패하면 원인과 해결 방법을 그대로 보여 준다.
  `SolidMap 은 매핑 가능한 블록만 헥사로 만듭니다. HyperMesh 에서 솔리드를 블록으로 나눠(Geom > Solid Edit > Trim) 저장한 CAD 나, 직접 만든 헥사 .inp 를 models 폴더에 넣어 주세요.`

### 2. 자동 헥사 (실험 기능, 기본 꺼짐) : `core/grid_hex.py`
블록으로 나누지 않은 솔리드를 **순수 헥사(C3D8H)** 로 만드는 메셔. 테트라는 전혀 쓰지 않는다.
- 단면 쓸기 방식 (축이 있는 형상, 부싱):
  1. 축 방향으로 내려다본 형상 그림자를 사각형 메시로 만든다 (gmsh, 얇은 고무막도 두께 방향으로 요소가 들어감).
  2. 축 방향으로 쌓는다. 끝면 같은 평면에 층을 맞춘다.
  3. 칸마다 형상 안에 든 부피 비율을 보고 고른다.
  4. 겉면에 패치(매끈하게 이어진 CAD 면 묶음)별로 경계층 헥사를 한 겹씩 넣고, 겉면 절점을 CAD 면, 모서리선, 꼭짓점에 붙인다.
  5. 평활화와 뒤집힌 요소 펴기를 한 뒤, 품질(scaled Jacobian)을 국부 최적화한다.
- 축이 없는 형상은 정육면체 격자 방식을 쓴다.
- 결과 그림은 `mesh/<모델>_hexmesh.png` 다 (겉면 품질 색, 축에 수직인 단면, 축을 지나는 단면, 품질 분포).
- 켜는 법: `config_abaqus.json` 의 `"hypermesh": {"hex_auto": true}`. 순서는 YL_HEX 를 먼저 시도하고, 안 되면 자동 헥사를 시도한다.
- 품질 기준: 최소 scaled Jacobian > 0.02, CAD 대비 부피 오차 ±10 % 이내. 못 넘으면 그 모델은 실패로 끝난다 (Tetra 로 넘어가지 않음).

## 자동 헥사 현재 상태 (그래서 기본은 꺼짐)
| 형상 | 결과 |
|---|---|
| bushing.stp (단순 원통 부싱) | 성공. 헥사 66,297개, 최소 SJ 0.379, 평균 0.966, 부피 오차 -0.03 %. 파이프라인 build -> 15/15 통과 (가짜 Abaqus) |
| Part2 (고무막 1 mm 안팎 + 바깥 링 끝 립) | 형상은 잡힘 (부피 오차 1~3 %). 다만 약 47,000개 중 200~300개가 바깥 링과 립이 이어지는 구간에서 뒤집힘 -> 실패 처리 |
| Part5, MID_POR | Part2 와 같은 계열. 아직 통과 못 함 |

- 정육면체 격자만으로는 1 mm 고무막을 2 mm 칸으로 표현할 수 없어서 형상의 80 %가 사라졌다. 그래서 단면 쓸기 방식으로 바꿨다.
- 테트라를 헥사 4개로 쪼개는 방식도 시험했다 (Part5, MID_DRT). 평균 SJ 0.45, 요소 수 4배, 일부 뒤집힘으로 품질이 나빠 쓰지 않는다.
- 다음 단계: 단면 메시가 바깥 링 벽 같은 내부 벽을 따라가게 해서 뒤집힘을 없앤다. 실제 7개 형상으로 시험해야 한다.

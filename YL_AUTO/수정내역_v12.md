# YL_AUTO v12 수정 내역 (2026-11-13, 원통이 아닌 형상도 자동 처리)

## 바뀐 점
예전에는 "원통형 부싱, CAD 원점 = 보어 중심, 축 = X/Y/Z 중 하나" 를 가정했다.
이제는 **관통 구멍(보어)만 있으면 어떤 단면 형상이든** 아래를 자동으로 한다.

| 항목 | 예전 (cylinder) | 지금 (general) |
|---|---|---|
| 축 | bbox 중심을 지나는 X/Y/Z 중 재료가 없는 직선 | 형상을 내려다봤을 때 관통 구멍이 보이는 방향. X/Y/Z 에 없으면 기울어진 축도 찾음 |
| 원점 | CAD 원점 그대로 | **보어 중심을 (0,0,0) 으로 이동**, 축 방향은 INNER 면의 가운데 |
| INNER | 반경이 가장 작은 띠 | 보어 구멍과 맞닿은 옆면 + 거기에 이어진 보어 쪽 옆면 |
| OUTER | 반경이 가장 큰 띠 | 그림자 바깥 윤곽과 맞닿은 옆면 |
| 스웨징 방향 | 반경 방향 | OUTER 가 원이면 반경 방향(예전과 동일), 아니면 **면의 법선 방향**(균일 오프셋) |

- 보어 옆의 공극(void)은 INNER 로 잡히지 않는다 (형상 중심에 가장 가까운 큰 구멍을 보어로 선택).
- 메시(HyperMesh/gmsh), Job INP, ODB 1개 방식, 리포트는 그대로다.

## 설정 (config_abaqus.json 의 geometry)
```
"shape_mode": "general",   // general | cylinder(예전 방식)
"center": "auto",          // auto(보어 중심 -> 0,0,0) | none | bbox
"swage_mode": "auto"       // auto | radial | normal
```
`inner_r_max` / `outer_r_min` 을 직접 지정한 모델은 자동으로 예전 방식을 쓴다.

## 한계
- **관통 구멍이 없는 형상(통 덩어리, 판 사이에 낀 블록 등)은 처리하지 못한다.** INNER 를 "관통 구멍의 벽"으로
  정의하기 때문이다. 이 경우 명확한 오류 메시지를 내고 그 모델만 건너뛴다.
- 외곽에 단차(플랜지)가 있으면 가장 바깥 윤곽의 면만 OUTER 가 된다 (예전의 "가장 큰 반경 띠"와 같은 규칙).

## 검증
- 기존 원통 모델 3개(BUSH_PLAIN, BUSH_VOID, 0.2 mm 양각 부싱) : 예전 방식과 INNER/OUTER 절점이 **완전히 동일** (차이 0개)
- 비원통 시험 형상 (gmsh 로 생성)
  - 타원 외곽 + 사각 구멍, 원점에서 50 mm 떨어짐 : INNER 2400 mm² (이론 2400), OUTER 7254 mm² (이론 7254), 법선 방향 오차 최대 2.8°
  - 사각 외곽 + 원형 구멍, 축이 기울어짐 : INNER 2539 (이론 2545), OUTER 8100 (이론 8100)
  - 플랜지 + 공극 2개, 보어 중심 오프셋 : 보어를 정확히 선택, 원점 이동 후 원형으로 판정
  - 구멍 없는 블록 : 오류 메시지 후 건너뜀
- **Abaqus 실제 해석은 이 환경에서 돌리지 못했다.** 비원형 OUTER 의 법선 방향 스웨징은 새 기능이므로
  첫 모델에서 `<tag>_SETS.png` (INNER/OUTER 그림)와 스웨징 스텝 변형을 한 번 눈으로 확인할 것.

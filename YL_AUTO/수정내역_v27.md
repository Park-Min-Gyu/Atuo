# YL_AUTO v27 수정 내역 (2026-11-27, 자동 헥사 기본 사용 + 새 모델 4개 헥사 메시·해석)

## 요약
- 자동 헥사(`core/grid_hex.py`)를 크게 고쳐서 **새 MID 부싱 4개(SNUBBER CASE03/04/06, DRT CASE06 4t)가 모두 순수 헥사로 메시**되었다.
  사람 손이나 블록 분할은 없고, 테트라는 쓰지 않았다.
- 4개 모두 파이프라인으로 끝까지 해석했다 (클라우드에는 Abaqus 가 없어 CalculiX 사용). 12/12 정상 종료.
- `hypermesh.hex_auto` 기본값을 **true** 로 바꿨다. YL_HEX(SolidMap)가 안 되면 자동 헥사를 시도한다.

## 자동 헥사에서 바뀐 것
| 항목 | v26 | v27 |
|---|---|---|
| 솔리드가 여러 개인 STEP (고무 본체 + 스너버) | 전부 합쳐서 처리 (부피 비교가 틀어짐) | **가장 큰 고무 본체만 메시**, 나머지 솔리드 부피는 로그에 표시 |
| 경계층 절점 처음 위치 | 이웃 겉면 절점의 평균 | 절점이 어느 패치의 경계층에서 생겼는지 기록 -> 그 패치 법선 방향으로 배치 (모서리선을 따라 요소가 납작해지지 않음) |
| 경계층 두께 | 고정 0.8 mm | 막 두께, 곡률, 바로 안쪽 칸 크기에 맞춰 줄임 |
| 뒤집힌 요소 펴기 | 고정 보폭 경사하강 (발산할 때 있음) | 짧은 펴기 + 전체 목적함수 줄찾기(단조 감소) + 국부 최적화(좋아질 때만 이동, 모서리선 절점도 선을 따라 이동) |
| 단면 사각형 크기 | 약 1 mm (요소 5만 개) | **약 2 mm 부터** 시도하고, 품질이 안 나오면 1.5 -> 1 mm 로 자동으로 잘게 |
| 단면 경계 점 간격 | 4 mm (뾰족한 끝에서 고무막이 끊김) | 2 mm (꺾인 점 보존) |

## CalculiX 대체 해석 (Abaqus 실사용과 무관)
- CalculiX 에는 하이브리드(H) 요소가 없다. 헥사를 C3D8 로 하면 거의 비압축 고무(FJ5045, K/mu = 333)에서 체적 잠김으로
  초기 강성이 약 25 % 높게 나왔다 (233 vs 190 N/mm). C3D8I 는 둘째 증분부터 발산했다.
  **감차적분 C3D8R** 은 잠김 없이 수렴했으므로 CalculiX 에서는 C3D8R 을 쓴다.
- Abaqus 용 INP 는 그대로 **C3D8H** 다.

- 2 mm 까지 거의 선형 (초기 강성과 할선 강성의 차이 3 % 이내).
- **스너버는 해석에 넣지 않았다.** STEP 마다 솔리드가 3 개(고무 본체 + 위아래 스너버)이고, 스너버는 본체와
  1.25 mm(SNUBBER) / 2.0 mm(DRT) 떨어져 있다. 접촉을 정의하지 않았으므로 CAD Z 방향 결과는 틈이 닫히기 전 거동이다.
  SNUBBER 는 1.25 mm 를 넘으면 실제 강성이 더 커진다.
- CalculiX C3D8R 과 Abaqus C3D8H 는 요소 정식화가 달라 값이 몇 % 다를 수 있다. 연구실 PC 에서 Abaqus 로 다시 돌리면 된다.

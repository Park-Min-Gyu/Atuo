# YL_AUTO v22 수정 내역 (2026-11-24, 한 번 해석한 모델 다시 안 돌리기)

## 예전 동작 (문제)
| 상황 | 예전 | 문제 |
|---|---|---|
| 전부 완료된 해석 | 다시 안 돌림 | 메시/세트/조건이 바뀌어도 안 돌려서 **옛 결과가 남음** (--force 를 잊으면) |
| 일부 케이스가 발산한 해석 (예: 13/15) | **매번 처음부터 다시 돌림** | Part3 처럼 13 시간 걸린 모델도 실행할 때마다 다시 |
| TetWild 로 만든 메시 | **매번 다시 메시** (모델당 20 분) | 재사용 판정에서 빠져 있었음 |
| 라이선스 문제로 Abaqus 가 시작 못 함 | 폴더에 남은 **지난번 결과 파일을 이번 결과로 착각** | 실행 안 됐는데 "완료"로 보고될 수 있었음 |

## 지금 동작
- 해석할 때 입력(Job INP + 메시 INP)의 **지문**을 기록한다.
- 다음 실행에서
  - 지문이 같고 지난번 해석이 끝까지 돌았으면 (발산해서 건너뛴 케이스 포함) **다시 안 돌린다**
    -> 로그 `이전 해석 결과 재사용 (13/15 케이스 완료, 입력 동일) -> 다시 돌리려면 --force`
  - 메시·INNER/OUTER·스웨징·하중 조건 등이 바뀌어 지문이 다르면 **자동으로 다시 돌린다**
    -> 로그 `해석 입력(메시/세트/조건)이 지난번과 달라 다시 해석합니다`
  - 라이선스 등으로 Abaqus 가 시작조차 못 했으면 '끝남'으로 보지 않고 다음 실행에서 다시 시도한다
- 결과 파일은 **이번 실행에서 새로 생긴 것만** 이번 결과로 본다 (남은 옛 .sta/.odb 무시).
- 메시는 YL_V10, gmsh, TetWild 어느 것으로 만들었든 재사용한다 (설정이 바뀌면 다시 메시).
- 강제로 전부 다시 : `run_all.bat --force`

## v21 이하로 해석한 결과
지문 기록이 없으므로 예전 규칙을 따른다 : 전부 완료면 재사용, 일부 발산이면 한 번 다시 돌린 뒤부터 새 규칙.

# YL_AUTO v19 수정 내역 (2026-11-24, Part2.stp 원본으로 원인 확인 + 자동 메시 성공)

## Part2.stp 를 직접 열어서 확인한 것
- STEP 안에는 **솔리드가 하나 들어 있다** (CATIA V5 AP242, `MANIFOLD_SOLID_BREP`, 부피 43,191 mm³).
- 그런데 OpenCASCADE 형상 검사에서 **"유효하지 않은 솔리드"** 로 나온다. HyperMesh 가 `solids after import : 0` 으로 읽은 이유로 보인다.
- 원인은 4 군데의 **넓이가 거의 0 인 면**(0.000007~0.00003 mm², 약 0.1 mm 크기의 조각)과 **길이 0 모서리**다.
  위치 (원본 CAD 좌표) : (25.0, 6.4, 26.8), (-25.0, 6.4, 26.8), (-25.0, -6.4, 26.8), (25.0, -6.4, 26.8)
  -> 네 곳이 대칭이라 필렛/모따기 끝이 만나는 곳에서 CATIA 가 남긴 찌꺼기 면으로 보인다.
- gmsh 는 이 면(488 번 등)을 메시하지 못해서 `Impossible to mesh periodic surface 488` 로 멈췄다.

## 해본 것
| 방법 | 결과 |
|---|---|
| gmsh 기본 / MeshAdapt | 488·350 번 면에서 실패 |
| gmsh 형상 수리(healShapes, 꿰매기) | 솔리드가 깨지거나 면이 두 배로 늘어남 |
| OpenCASCADE 작은 모서리 정리 | 솔리드는 유효해지지만 작은 면이 그대로 남아 실패 |
| OpenCASCADE 작은 면 제거(defeaturing) | 아무것도 제거하지 못함 |
| 삼각형 면으로 바꾼 뒤 다시 메시 | 재매개변수화 실패 |
| **원본 형상 그대로, 작은 면만 직접 채우며 메시** | **성공 (Tetra 62,604개, 12초)** |

## 수정 : gmsh 예비 메셔에 "작은 면 직접 채우기" 방법 추가 (2 번째 시도)
1. 넓이 0.001 mm² 미만인 면은 경계 절점으로 삼각형을 직접 만들어 넣음
2. 나머지 면은 gmsh 가 정상 메시
3. 같은 위치 절점 병합, 직접 채운 면의 방향을 이웃 면과 맞춤
4. 그래도 남은 아주 작은 구멍(둘레 8 mm 이하)만 메우고 3D 메시. 그보다 큰 구멍은 형상 문제라 메우지 않음

원래 형상은 바뀌지 않고, 직접 채운 부분은 0.1 mm 크기의 면뿐이다.

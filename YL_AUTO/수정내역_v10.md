# YL_AUTO v10 수정 내역 (2026-11-13, Abaqus Job 15개가 전부 2초 만에 끝나는 문제)

## 증상
- 메시/빌드는 정상 (`mesh OK tet=86340`, `build OK: C3D10H`), Abaqus 도 찾았음 (`Abaqus: C:\SIMULIA\Commands\abaqus.bat (auto)`)
- 그런데 Job 15개가 모두 `completed=False inc=0 t=2.1s`, run 폴더에 `.dat/.sta/.odb` 가 하나도 없음
  -> Abaqus 가 해석을 돌리다 실패한 것이 아니라 **abaqus 명령이 Job 을 시작하기 전에 거부**된 것

## 원인 (추정, runlog 를 못 봐서 확정은 아님)
`core/runners.py` 가 `abaqus job=... cpus=4 interactive ask_continue=off` 로 실행했는데
Abaqus 에 `ask_continue` 라는 옵션은 없다 (이전 결과를 묻지 않고 덮어쓰는 옵션은 `ask_delete=OFF`).
또 실패 이유가 적힌 `<job>.runlog` 내용을 화면/pipeline_log.txt 에 보여 주지 않아서 원인을 알 수 없었다.

## 수정
- `core/runners.py: run_abaqus`
  - `ask_continue=off` -> `ask_delete=OFF`
  - Job 파일이 하나도 안 생기면(명령 거부) 옵션을 줄여 자동 재시도: ① cpus+ask_delete ② ask_delete 만 ③ 옵션 없이
  - 남아 있는 `.lck` 잠금 파일 삭제, 입력 대기(stdin)로 멈추지 않게 처리
  - 실패 시 `<job>.runlog` 의 오류 줄을 status 에 저장
- `run_pipeline.py` : Job 실패 시 실행 명령과 runlog 오류 줄을 로그에 출력 (처음 3개 Job 만 자세히)

## 다시 실행 (메시는 다시 안 만들고 해석만)
```
run_all.bat --stage run,extract,report
```
또 실패하면 pipeline_log.txt 의 `runlog|` 줄에 Abaqus 가 낸 실제 오류 문장이 나온다.

# YL_AUTO v20 수정 내역 (2026-11-23, 연구실 YL_V10 자동 메시 통합)

## 합친 것
연구실에서 만든 **YL_V10** (HyperMesh BatchMesher 스킨 엔진)을 파이프라인의 메시 단계로 넣었다.
지금까지 만든 것(원점/INNER/OUTER 자동, ODB 1개, 발산 시 이어서 계산, 메시 품질 보정, 2 mm 고정, gmsh 예비 메셔 등)은 그대로다.

```
CAD (.stp)
 └ 메시 단계
    1) YL_V10 - V9 엔진 : BatchMesher 스킨 -> 찌꺼기 면 정리 -> 수리 -> 2D 검사
    2)          V8 엔진 : V9 스킨이 합격 못 하면 새 hmbatch 프로세스에서 (YL_V10.ps1 과 같은 순서)
    3)          2D 합격 -> 같은 세션에서 Tetra -> C3D10H -> Abaqus INP
    4) gmsh 예비 메셔 (v19 '작은 면 직접 채우기' 포함)  <- V9, V8 모두 실패할 때만
 └ build / run / extract / report : 그대로
```

## 파일
| 파일 | 내용 |
|---|---|
| `hypermesh/YL_V10/YL_V10.ps1`, `YL_V10.bat` | 받은 원본 그대로 (한 글자도 안 바꿈). 단독 실행(설정 창, 2D 스킨만)도 그대로 됨 |
| `core/yl_v10.py` (신규) | YL_V10.ps1 끝의 엔진 Tcl 5개를 실행할 때마다 꺼내서 hmbatch 로 실행, 결과(batch_summary.csv)를 파이프라인 형식으로 변환 |
| `run_pipeline.py` | 메시 단계에서 `hypermesh.engine` 이 `v10` 이면 YL_V10 사용 |
| `config_abaqus.json` | `hypermesh.engine: "v10"`, `v10_aspect`, `v10_v8_fallback`, `v10_fillet_rows`, `v10_then_v5` |
| `core/findexe.py` | `YL_HMBATCH` 환경변수, `Altair/2019/2019/hm/...` 설치 형태도 찾음 (YL_V10 과 같게) |
| `check_env.py` | YL_V10 엔진을 꺼낼 수 있는지 확인 |

**YL_V10.ps1 을 새로 빌드하면 `hypermesh/YL_V10/YL_V10.ps1` 만 바꿔 넣으면 된다.** 엔진은 실행할 때마다 그 파일에서 다시 꺼낸다.

## YL_V10 과 다르게 동작하는 점 (자동 해석용으로 켠 것)
| 항목 | YL_V10 단독 | 파이프라인 |
|---|---|---|
| 3D (Tetra) | 안 만듦 (2D 스킨만, 3D 는 손으로) | **2D 가 합격한 경우만** 같은 세션에서 만듦 (`YL_V9_ALLOW_3D=1`, `YL_DO_TETRA=1`) |
| Abaqus INP | 안 씀 | 씀 (`YL_EXPORT_INP=1`) -> build 단계가 읽음 |
| Tetra 성장률 | 1.2 | `mesh.fixed_size: true` 면 **1.0** (꺼낸 복사본의 `set TET_GROWTH` 한 줄만 바꿈, 원본 ps1 은 그대로) |
| 요소 타입 | - | C3D10H (`mesh.elem_type`) |

## 결과 파일 (모델별 `auto_out/<모델>_Ep2p0/mesh/`)
- `<모델>.hm` (YL_V10 결과), `<모델>.inp` (YL_V10 이 쓴 INP), `<모델>_hm.inp` (build 단계가 읽는 복사본)
- `hm_status.txt` : `ALGO=YL_V10_V9` 또는 `YL_V10_V9>V8`, 스킨 품질(q 평균), Tetra aspect p95, collapse 비율
- `_logs/` : `batch_log_V9.txt`, `batch_summary_V9.csv`, (V8 로 갔으면 `_V8`), `hm_console_V9.log`

## 처음 실행할 때
- 예전 엔진(YL_V5)으로 만든 메시는 재사용하지 않고 **모든 모델을 YL_V10 으로 다시 메시**한다.
- 예전 방식으로 돌리려면 `"engine": "v5"`.

## 검증 범위
- YL_V10.ps1 에서 엔진 5 개를 꺼내는 것 : 줄 수가 원본과 같고 Tcl 문법(괄호 짝)이 온전한 것 확인
- 가짜 hmbatch(run_batch.tcl 의 결과 형식만 흉내)로 세 경우 확인 : V9 합격 / V9 실패 -> V8 합격 / 둘 다 실패 -> gmsh
- 기존 시험 모델 build 결과 변화 없음
- **실제 HyperMesh 에서 YL_V10 + 3D + INP 출력을 파이프라인으로 돌려 보지는 못했다.**
  YL_V10 단독에서는 3D 를 끈 상태(2D 전용)라, 엔진의 3D 단계(`YL_V9_ALLOW_3D=1`)는 연구실에서도 최근에 안 돌았을 수 있다.
  첫 실행 때 `mesh/_logs/batch_log_V9.txt` 의 `Tetra mesh:` 줄과 `Abaqus deck:` 줄을 확인할 것.

# YL_AUTO 사용설명서 (연구실 공용)

부싱 CAD 형상(.stp 등)과 고무 물성을 넣으면
**HyperMesh 2019 메시 → Abaqus INP 작성 → Abaqus 2021 해석 → ODB 에서 하중-변위 추출 → 강성·QC 보고서**
까지 한 번에 돌리는 코드입니다. 처음 쓰는 사람도 이 문서 순서대로만 하면 되게 써 두었습니다.

## 1. 설치 (PC 마다 처음 1번)

### 1-1. 필요한 프로그램

| 프로그램 | 버전 | 비고 |
|---|---|---|
| Altair HyperMesh | 2019 | `hmbatch.exe` 를 사용 (GUI 안 뜸) |
| Abaqus | 2021 | `abaqus` 명령 사용 (CAE 안 뜸). 라이선스 서버 연결 필요 |
| Python | 3.9 이상 (3.10~3.12 권장) | Abaqus 내장 Python 아님. 따로 설치 |

### 1-2. Python 설치

1. python.org 에서 Windows 설치 파일을 받는다.
2. 설치 첫 화면에서 **"Add python.exe to PATH" 체크** 후 Install.
3. 명령 프롬프트(cmd)를 새로 열고 확인:
   ```
   python --version
   ```
4. 패키지 설치:
   ```
   pip install numpy scipy matplotlib
   ```
   회사·학교망에서 막히면 `pip install --user numpy scipy matplotlib` 또는 담당자에게 문의.

### 1-3. 코드 위치

바탕화면·OneDrive·한글 폴더명 아래는 Abaqus 가 경로를 못 읽는 경우가 있어서 피한다.

### 1-4. 프로그램 경로 (자동 탐색)

`config_abaqus.json` 에 이미 아래처럼 들어 있다. **대부분 그대로 두면 된다.**

```json
"hypermesh": { "exe": "auto",
  "start_menu_dir": "C:/ProgramData/Microsoft/Windows/Start Menu/Programs/Altair 2019" },
"abaqus":    { "cmd": "auto", "version": "2021",
  "start_menu_dir": "C:/ProgramData/Microsoft/Windows/Start Menu/Programs/Dassault Systemes SIMULIA Established Products 2021" }
```

`auto` 일 때 찾는 순서:

| 대상 | 찾는 순서 |
|---|---|
| HyperMesh | ① 시작메뉴 폴더 안 바로가기(.lnk)가 가리키는 실제 경로 → 같은 폴더의 `hmbatch.exe` ② `C:/Program Files/Altair/2019/hm/bin/win64/hmbatch.exe` ③ PATH |
| Abaqus | ① 시작메뉴 폴더 바로가기 → `abaqus.bat` / `abq2021.bat` ② `C:/SIMULIA/Commands/abaqus.bat`, `abq2021.bat` ③ PATH |

시작메뉴 폴더에는 실행 파일이 아니라 **바로가기**만 있다. 코드가 바로가기 대상을 읽어서 실제 설치 위치를 찾는다.

자동으로 못 찾으면 직접 적는다 (슬래시 `/` 사용, 역슬래시 쓰면 `\\` 두 번):

```json
"hypermesh": { "exe": "C:/Program Files/Altair/2019/hm/bin/win64/hmbatch.exe", ... },
"abaqus":    { "cmd": "C:/SIMULIA/Commands/abq2021.bat", ... }
```

실제 경로 확인 방법: 시작메뉴에서 HyperMesh 2019 / Abaqus Command 아이콘 우클릭 → 자세히 → 파일 위치 열기 → 바로가기 우클릭 → 속성 → "대상".

## 4. 실제 해석

### 4-1. CAD 준비 체크리스트 (중요)

해석 결과 품질은 대부분 여기서 결정된다. CATIA 에서 STEP 으로 내보내기 전에 확인한다.

| 항목 | 기준 | 이유 |
|---|---|---|
| 단위 | mm | 물성 MPa, 하중 N 기준 |
| 바디 | **고무 바디 1개만** (내·외통 금속 제외) | 금속은 INNER/OUTER 구속으로 대신함 |
| 원점 | 부싱 중심이 (0,0,0) | LOAD_RP 를 (0,0,0)에 만듦 (`center: bbox` 로 자동 이동도 가능) |
| 축 | X, Y, Z 중 하나와 평행 | 자동으로 +Y 로 회전함. 기울어진 축은 안 됨 |
| 각인·문자·점 표시 | **삭제 후 내보내기** | 0.2 mm 양각 글자·R0.25 점 표시만으로도 요소가 수만 개 늘어남 (아래 사례) |
| 작은 필렛·모따기 | 0.5 mm 이하는 가능하면 삭제 | 요소 수 증가, 찌그러진 요소 원인 |
| 파일명 | 영문·숫자·`_` 만 | Job 이름에 그대로 들어감 |

**실제 사례 (Test_2026.stp, CATIA V5R20)**: 고무 바디 1개, 면 5,207개 중 약 4,600개가 각인 글자(+X 끝면 x=19.0→19.2, 포켓 바닥 x=17.0→17.2, 높이 0.2 mm)이고, 플랜지 끝면(x=±23.75)에 R0.25 점 표시 224개가 있었다.
글자를 지우지 않고 메시하면 절점 약 13만 개 / 사면체 47만 개가 나왔고, 글자를 지운 뒤에도 글자 윤곽선 자국과 점 표시 때문에 절점이 끝면에 몰렸다.
**CATIA 에서 각인·점 표시 피처를 비활성화(Deactivate)한 뒤 STEP 으로 내보내는 것이 가장 확실하다.**
HyperMesh 에서 지울 경우 Geometry 의 defeature 패널(pinholes, surf fillets 등)이나 면 삭제 후 면 재생성으로 정리한다 (HM 2019 메뉴 이름은 연구실 PC 에서 확인 필요).

`models\` 폴더에 CAD 를 넣으면 **폴더 안 파일 전부**를 자동으로 돈다 (`"models_glob": "models/*"`).


지원 확장자: `.stp .step .igs .iges .x_t .x_b .CATPart .prt .sat .hm` (HyperMesh 가 읽는 것) 와 `.inp` (이미 메시가 된 INP — 이 경우 HyperMesh 단계는 건너뜀).

### 4-3. 실행

```
cd /d C:\YL_AUTO
run_all.bat
```

`run_all.bat` 이 하는 일: 환경 점검(`auto_out\check_env.txt`) → `run_pipeline.py config_abaqus.json` (화면 내용이 `auto_out\pipeline_log.txt` 에도 저장됨) → 로그 zip. 끝나면 창이 바로 닫히지 않고 `계속하려면 아무 키나 누르십시오` 에서 멈추므로 화면 메시지를 확인할 수 있다.

한 모델당 Job 수 = 스웨징 5개 × 방향 3개 = **15 Job** (요소크기를 여러 개 넣으면 그 배수).
중간에 꺼져도 **같은 명령을 다시 치면 끝난 Job 은 건너뛰고 이어서** 돈다.

단계를 나눠서 돌리고 싶을 때:

```
python run_pipeline.py config_abaqus.json --stage mesh,build      (메시와 INP 까지만. SETS 그림 확인용)
python run_pipeline.py config_abaqus.json --stage run,extract,report (해석과 결과만)
python run_pipeline.py config_abaqus.json --only Test_2026         (특정 모델만)
python run_pipeline.py config_abaqus.json --only Test_2026 --force (특정 모델 처음부터 다시)
```

**처음 보는 형상은 꼭 `--stage mesh,build` 로 먼저 돌려서 `_SETS.png` 를 확인한 뒤** 해석을 돌린다 (6-2절).

## 5. 내부에서 하는 일 (단계별)

```
models\Test_2026.stp
  │ [mesh]  hmbatch.exe -tcl hm_wrapper.tcl  (YL_V5 = YL_V4 메시 알고리즘 + 배치 래퍼)
  │         → auto_out\Test_2026_Ep2p0\mesh\Test_2026_hm.inp, hm_log.txt, hm_status.txt
  │ [build] Python
  │         ① INP 읽기, 사면체 절점순서·체적부호 검사, tet4 이면 tet10 으로 변환
  │         ② 부싱 축 자동 판별(X/Y/Z) → 무조건 +Y 로 회전 (반경방향 = XZ 평면)
  │         ③ INNER / OUTER 면 자동 선택, LOAD_RP (0,0,0) 생성
  │         ④ 메시 INP + Job INP 15개 작성, SETS 그림, model_info.json
  │ [run]   abaqus job=... cpus=4 interactive  → .odb
  │ [extract] abaqus python extract_odb.py     → <job>_RP.csv (U1~3, RF1~3)
  │ [report] 강성 계산, QC, summary.csv / curves.csv, FD 그래프
```

### 5-1. 해석 조건

| 항목 | 내용 |
|---|---|
| 축 | 원래 CAD 축 → **+Y** 로 회전. 반경 = XZ 평면 |
| LOAD_RP | (0,0,0). 절점번호 = 고무 최대 절점번호 + 1 |
| INNER | 축을 향하는 안쪽 면 중 가장 안쪽에서 시작해 이어진 면 전체 (`inner_mode: connected`) → `*Rigid Body, ref node=LOAD_RP, tie nset=INNER` (연구실 modeling_AN_M1.inp 방식) |
| OUTER | 바깥을 향하는 면 중 최대 반경 띠 (r ≥ r_max − 0.5 mm) |
| Step-1 스웨징 | OUTER 에 반경변위 u_r = SW, u_y = 0. SW = 0, +1, +2, −1, −2 mm. **+ = 바깥으로 늘어남, − = 안쪽으로 압축** |
| Step-2 정특성 | OUTER 고정, LOAD_RP 를 X / Y(축) / Z 로 2 mm 변위제어, 나머지 자유도 0 |
| 재료 | `*Hyperelastic, n=3, ogden` (기본 FJ5045) |
| 요소 | C3D10H |
| 기타 | NLGEOM=YES |

Job 이름 규칙: `모델_E요소크기_SW스웨징_방향` → 예 `Test_2026_Ep2p0_SWm1p0_XP` (p = 소수점, m = 마이너스, XP = +X 방향).

## 6. 결과 보는 법

### 6-1. 결과 폴더

```

 └─ Test_2026_Ep2p0\
     ├─ Test_2026_Ep2p0_SETS.png ← ★ INNER/OUTER 가 맞게 잡혔는지 그림
     ├─ Test_2026_Ep2p0_FD.png   ← 방향별·스웨징별 하중-변위 곡선
     ├─ model_info.json          ← 축 판별, 세트 면적·반경, 메시 품질

```

ODB 는 `run\` 안에 있으므로 Abaqus CAE (Visualization) 로 그대로 열어 볼 수 있다.

### 6-2. SETS 그림 확인 (형상이 바뀌면 반드시)

- 파란 점 = INNER (내통에 붙는 면), 빨간 점 = OUTER (외통에 붙는 면), 별 = LOAD_RP
- 확인할 것: **실제 금속과 붙는(접착) 면만** 색이 칠해졌는지.
  - 자유 표면(공극 내부, 끝면)이 칠해졌으면 잘못된 것
  - 접착면인데 빠진 곳이 있으면 잘못된 것
- 그림 제목에 INNER/OUTER 면적(mm²)과 반경 범위가 나온다. CAD 에서 잰 접착면 면적과 비교한다.

잘못 잡혔을 때 고치는 설정 (모델별로 `models` 목록에 적거나 `geometry` 에 공통으로):

| 증상 | 설정 | 예 |
|---|---|---|
| 축 판별이 틀림 | `"axis": "X"` (원래 CAD 축) | |
| OUTER 에 안쪽 단차 면까지 들어감 / 빠짐 | `"outer_tol_mm"` (기본 0.5) 줄이기/늘리기, 또는 `"outer_r_min": 28.0` | r ≥ 28.0 인 바깥면만 |
| INNER 가 공극 면까지 퍼짐 | `"connect_rmax_frac"` (기본 0.6) 줄이기, 또는 `"inner_r_max": 20.0` | r ≤ 20 인 안쪽 면만 |
| INNER 가 원통 1개 반경만 필요 | `"inner_mode": "band"` + `"inner_tol_mm"` | |
| 원점이 중심이 아님 | `"center": "bbox"` | 바운딩박스 중심을 원점으로 |

모델별로 지정하는 법 (`models_glob` 와 같이 써도 됨, 이름이 겹치면 오류):

```json
"models_glob": "",
"models": [
  { "name": "Test_2026", "file": "models/Test_2026.stp", "axis": "X", "outer_r_min": 29.0 },
  { "name": "M02",       "file": "models/M02.stp", "material": "FJ5045" }
]
```

### 6-3. qc_report.md 항목 뜻

| 항목 | 뜻 | WARN/FAIL 이면 |
|---|---|---|
| `completed_full_step` | 하중 Step 이 step time 1.0 까지 감 | 수렴 실패. `run\<job>.msg` 끝부분, 메시 품질 확인 |
| `reached_amplitude` | 목표 변위(2 mm) 도달 | 위와 같음 |
| `enough_points` | 곡선 점이 6개 이상 | 증분이 너무 큼 → `steps.load_inc` 최대값 줄이기 |
| `monotonic_force` | 하중이 계속 증가 | 큰 압축에서 요소 찌그러짐 가능. 메시 세분화 |
| `positive_stiffness` | 강성 > 0 | 세트·부호 확인 |
| status `FAIL` (Job 자체) | Abaqus 비정상 종료 (`.sta` COMPLETED 없음, `***ERROR`) | `.msg`, `.dat`, `.log` 확인 |
| 모델 단위: Kx/Kz 대칭 | 축대칭 형상이면 1 근처 | 공극이 있는 비대칭 형상이면 원래 1 이 아님 (정상) |
| 모델 단위: 스웨징 경향 | SW − 일수록 반경 강성 증가 | 반대면 세트/부호 확인 |

표에 `all OK` 이면 전부 통과. 스웨징 후 LOAD_RP 잔류 반력은 summary.csv 의 `swage_RF_end` 에 있다 (비대칭 형상이면 0 이 아닐 수 있음).

## 8. 물성 넣기

### 8-1. 계수를 알고 있을 때 (현재 FJ5045)

```json
"FJ5045": {
  "ogden3": { "mu": [0.75744, 0.0013173, 0.00049209], "alpha": [1.3475, 11.347, -5.3698] },
  "D": [0.0079104, 0.0, 0.0]
}
```
Abaqus 정의 그대로의 μi, αi, Di 이다 (modeling_AN_M1.inp 에서 가져온 값).

### 8-2. 시험데이터로 피팅할 때

1. `materials\` 에 CSV 저장. 2열 `공칭변형률, 공칭응력(MPa)`, 첫 줄 헤더 가능.
   - `XXX_uniaxial.csv` (단축), `XXX_biaxial.csv` (등이축), `XXX_planar.csv` (평면) — 있는 것만
2. config 에 추가:
   ```json
   "MY_RUBBER": {
     "test_data": { "uniaxial": "materials/XXX_uniaxial.csv",
                    "biaxial":  "materials/XXX_biaxial.csv",
                    "planar":   "materials/XXX_planar.csv" },
     "stable_range": [0.2, 5.0],
     "bulk_modulus": 2000.0
   }
   ```
3. `"default_material": "MY_RUBBER"` 또는 모델별 `"material": "MY_RUBBER"`.
4. 실행하면 `auto_out\materials_ogden3.json` 에 피팅 계수, R², 안정 구간이 저장된다.

`materials\TEST_RUBBER_*.csv` 는 **가상 데이터**이므로 실제 해석에 쓰면 안 된다.

| build ERROR `INNER/OUTER 에 동시에 속한 절점` | `error.txt` | 얇은 형상. `inner_tol_mm`, `outer_tol_mm` 줄이기 |

## 11. 아직 실제 장비에서 확인 못 한 부분

코드는 HyperMesh·Abaqus 가 없는 환경에서 작성했고, 메시는 gmsh, 솔버는 CalculiX 로 대신 돌려 흐름을 검증했다.
첫 실행 때 아래를 확인해야 한다.

1. `hmbatch.exe -tcl` 로 YL_V5 가 끝까지 도는지, `*geomimport` 옵션 문자열이 2019 에서 맞는지
2. `*feoutputwithdata` 로 나온 INP 위치·요소 종류 (Python 이 다시 검사하므로 tet4/tet10 어느 쪽이든 처리됨)
3. 시작메뉴 바로가기(.lnk)로 경로 자동 탐색이 되는지 (check_env 출력 확인)
4. ODB history region 이름 (못 찾으면 field output 으로 자동 대체)
5. 실제 접착면이 SETS 그림과 같은지 (형상마다 사람이 확인)
6. 스웨징 부호 (+ 바깥, − 안쪽) 가 연구실 기존 정의와 같은지

# Atuo: PDF 자동 번역기

PDF를 주면 알아서 번역하고, 번역본 PDF와 요약본을 만들어 줍니다.

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=발급받은_키
python autotrans.py 문서.pdf
```

결과는 `output/` 폴더에 생깁니다.

| 파일 | 내용 |
|---|---|
| `문서.번역본.pdf` | 원본 레이아웃(그림, 표, 선)은 그대로, 글자만 번역문으로 교체 |
| `문서.요약.pdf`, `문서.요약.md` | 번역본의 요약 |
| `문서.검증.md` | 누락 검사 결과 |

## 옵션

```bash
python autotrans.py 받은문서폴더/        # 폴더 안의 PDF 전부
python autotrans.py a.pdf b.pdf -o 결과  # 여러 파일, 결과 폴더 지정
python autotrans.py 문서.pdf --to 영어   # 다른 언어로 (기본: 한국어)
```

원문 언어는 지정하지 않아도 됩니다(영어, 일본어 등 자동 인식).

## 건너뛰는 말이 없도록 하는 방법

1. PDF의 모든 텍스트 블록에 번호를 붙여서 번역시키고, 돌아온 번역에 모든 번호가 있는지 확인합니다.
2. 빠진 번호, 빈 번역, 원문에 비해 지나치게 짧은 번역은 다시 번역시킵니다. 마지막에는 조각을 하나씩 따로 보냅니다.
3. 그래도 실패한 조각은 원문 그대로 남기고 `검증.md`에 쪽수와 함께 적습니다. 조용히 사라지는 문장은 없습니다.
4. 글자 정보가 없는 스캔 페이지는 이미지를 읽어 번역하고, 번역문을 해당 쪽 바로 뒤에 새 쪽으로 넣습니다.

## 알아둘 점

- 번역문이 원문보다 길면 같은 자리에 맞추기 위해 글자가 작아집니다. 많이 작아진 곳은 `검증.md`에 나옵니다.
- 쪽번호처럼 글자가 없는 숫자, 기호 블록은 번역하지 않고 그대로 둡니다.
- 그림 안에 들어 있는 글자(도표 이미지 속 라벨 등)는 번역되지 않습니다.
- PDF 처리는 PyMuPDF(AGPL 라이선스)를 사용합니다. 글자를 지우고 같은 자리에 번역문을 넣는 방식은 PyMuPDF의 번역 예제와 PDFMathTranslate, BabelDOC 같은 오픈소스 번역기와 같은 접근입니다.

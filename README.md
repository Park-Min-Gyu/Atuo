# 문서 정리 AI

대충 적은 메모(날짜, 할 일, 사람 이름 등)나 정리 안 된 엑셀을 넣으면,
알아서 정리해 **한글 문서(.hwpx)** 와 **엑셀(.xlsx, 표 + 그래프)** 로 만들어 줍니다.

- 메모가 짧아도 회의록·보고서·계획서 등 문서 종류에 맞는 구성으로 채워 줍니다.
- 메모에 없는 사실(날짜, 금액, 이름)은 지어내지 않고 "미정"으로 두고, 무엇을 더 알려주면 되는지 따로 알려 줍니다.
- 엑셀은 머리글 색, 숫자 서식(천 단위 쉼표), 합계 수식, 필터, 그래프(막대/꺾은선/원)를 자동으로 넣습니다.

## 실행 (API 키 없이 바로 사용)

1. [Python](https://www.python.org/downloads/) 3.10 이상 설치 (설치 화면에서 "Add Python to PATH" 체크)
2. Windows: `run.bat` 을 더블클릭하면 브라우저가 열립니다.

직접 실행하려면:

```bash
pip install -r requirements.txt
```

```bash
python app.py
```

그다음 브라우저에서 http://localhost:5000 을 엽니다.

## 두 가지 정리 방식

| | 기본 정리 (키 없음) | AI 정리 (키 있음) |
|---|---|---|
| 비용 / 인터넷 | 무료, 인터넷 불필요, 내용이 밖으로 나가지 않음 | 쓴 만큼 요금, 내용이 Anthropic 서버로 전송됨 |
| 날짜·사람·할 일·기한 찾기 | 정해진 규칙으로 찾음 ("다음주 금요일까지", "김과장" 등) | 문맥을 이해해서 찾음 |
| 숫자 → 표·그래프 | "서울 1억2천, 부산 8천"처럼 쉼표로 나열한 숫자 | 자유로운 형태 |
| 문장 다듬기, 문서 구성 | 못 함 (메모 문장을 그대로 옮김) | 공문서 문체로 다듬고 종류에 맞게 구성 |
| 올린 엑셀 정리 | 제목 행·빈 행·합계 행 제거, 숫자 서식, 합계, 그래프 | 위 내용 + 표 구조 자체를 다시 짬 |

키를 넣지 않으면 자동으로 기본 정리로 동작합니다. AI 정리를 쓰려면 [console.anthropic.com](https://console.anthropic.com) 에서 키를 만든 뒤 명령 프롬프트에서:

```bash
setx ANTHROPIC_API_KEY "여기에_키_붙여넣기"
```

(창을 닫고 새로 연 뒤 다시 실행하면 적용됩니다.)

기본 정리가 잘 알아듣는 메모 쓰는 법:
- 첫 줄에 날짜와 제목 (`11/20 영업팀 주간회의, 3층 회의실`)
- 사람은 직함과 함께 한 번은 적기 (`참석 김민수 과장, 이지은 대리`)
- 할 일은 한 줄에 하나씩, 기한은 `~까지` 로 (`이지은 대리가 다음주 금요일까지 보고`)
- 숫자는 쉼표로 나열 (`3분기 매출 - 서울 1억2천, 부산 8천`)

## 알아둘 점

- 한글 파일은 **.hwpx** 형식입니다. 한컴오피스 한글 2014 이후 버전에서 그대로 열리고, 예전 `.hwp` 가 필요하면 한글에서 "다른 이름으로 저장"하면 됩니다. (`.hwp` 는 한글 프로그램 없이는 만들 수 없는 형식입니다.)
- 올리는 엑셀은 `.xlsx` / `.csv` 만 되고, 칸 20,000개까지입니다.
- 만든 파일은 이 컴퓨터의 `output/` 폴더에 저장됩니다.

## 구성

| 파일 | 역할 |
|---|---|
| `app.py`, `templates/index.html` | 브라우저 화면 |
| `local_planner.py` | 기본 정리: 규칙으로 메모·엑셀을 분석해 문서 설계도를 만드는 부분 |
| `planner.py` | AI 정리: Claude에게 메모를 보내 문서 설계도를 받는 부분 |
| `hwpx_writer.py` | 설계도 → 한글 문서 ([python-hwpx](https://github.com/airmang/python-hwpx) 사용) |
| `xlsx_writer.py` | 설계도 → 엑셀 표·그래프 ([openpyxl](https://openpyxl.readthedocs.io) 사용) |
| `reader.py` | 올린 엑셀/CSV 읽기 |

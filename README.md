# Atuo 수면패턴

폰을 하다가 잠드는 사람을 위한 안드로이드 수면 패턴 분석 앱.
별도 조작 없이 **폰 화면이 꺼진 시각과 다시 직접 켠 시각**만으로 수면을 추정하고, 일주일 단위로 분석해 알려 준다.

## 판단 규칙

| 상황 | 판정 |
| --- | --- |
| 마지막으로 화면이 꺼짐 | 잠든 시각 |
| 사용자가 잠금을 풀고 폰을 켬 (`ACTION_USER_PRESENT`) | 깨어 있음 → 기상 시각 |
| 알림·전화·알람·충전으로 화면만 켜짐 (잠금 해제 없음) | 무시 (계속 자는 중) |
| 자다가 직접 폰을 켜서 잠깐 쓰고 다시 잠 | 한 밤으로 묶되, 쓴 시간은 수면에서 빼고 "깸"으로 기록 |
| 알림 없이 화면만 잠깐 켜짐 (알림 접근 권한 허용 시) | "잠깐 확인"으로 횟수만 기록 |
| 낮·저녁에 폰을 오래 안 봄 | 수면 아님 (밤 시간대 확인) |
| 추적 서비스가 꺼져 있던 구간과 겹침 | "기록 공백"으로 표시 |

"알림으로 켜진 화면"과 "내가 켠 화면"은 두 단계로 구분한다.

1. **잠금 해제 여부** — 알림은 화면을 켤 수는 있어도 잠금을 풀 수는 없다. 권한 없이 항상 동작한다.
2. **알림 시각 대조** (선택, 알림 접근 권한) — 화면이 켜진 순간 앞뒤로 알림이 있었는지 확인한다.
   잠금화면이 없는 기기에서도 구분할 수 있게 되고, 알림 없이 켜진 화면은 "잠깐 확인"으로 따로 센다.
   알림의 시각만 기록하며 앱 이름이나 내용은 읽지 않는다.

## 구조

- `core/` — 순수 Kotlin 분석 엔진 (`SleepEngine`, `WeeklyAnalyzer`). 안드로이드 없이 단위 테스트한다.
- `app/` — 안드로이드 앱 (Jetpack Compose).
  - `track/TrackingService` — 화면 켜짐/꺼짐/잠금 해제를 기록하는 포그라운드 서비스
  - `track/NotificationSignalService` — 알림 시각 기록 (선택)
  - `track/UsageBackfill` — 서비스가 꺼져 있던 구간을 시스템 사용 기록으로 복원 (선택)
  - `track/WeeklyNotifier` — 7일마다 주간 리포트 알림
  - `ui/SleepScreen` — 주간 리포트, 7일 차트, 밤별 기록, 설정

모든 데이터는 기기 안의 SQLite 에만 저장되며 인터넷 권한이 없다.

## 빌드

```
./gradlew :core:test :app:testDebugUnitTest   # 테스트
./gradlew :app:assembleDebug                  # app/build/outputs/apk/debug/app-debug.apk
```

GitHub Actions 가 푸시마다 테스트 후 APK 를 `atuo-sleep-debug-apk` 아티팩트로 올린다.
Android 8.0 (API 26) 이상.

## 한계

- 화면을 켠 채(영상 재생 등) 잠들면 화면이 꺼질 때까지 깨어 있는 것으로 본다.
- 알람을 잠금화면에서 끄고 폰을 열지 않으면, 처음 잠금을 푼 시각이 기상 시각이 된다.
- 아침에 폰을 잠깐(5분 이하) 확인한 뒤 90분 넘게 폰을 안 보면 "다시 잠든 것"으로 본다.
- 제조사 배터리 절전이 서비스를 종료시키면 기록이 끊긴다. 앱의 "배터리 최적화 제외"를 켜 두는 것을 권장한다.
